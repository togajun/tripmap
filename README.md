Powered by Laravel and enhanced with Leaflet.js, Tripmap makes travel logs intuitive and visually appealing. </p>
✨ Features
📍 Interactive Map
Pin locations and share your travel experiences directly on a dynamic map interface.

📸 Image Uploads
Upload photos for each destination to make your journey more memorable.

🏷️ Categorize Your Trips
Classify your posts by categories (e.g., Nature, Culture, Food) for easy filtering.

🗺️ Prefecture-Based Mapping
Supports posts by prefectures in Japan, making it perfect for documenting regional travels.

🚀 Installation
Follow these steps to set up the project locally:

Clone the repository:

bash
コードをコピーする
git clone https://github.com/your-username/tripmap.git
cd tripmap
Install dependencies:

bash
コードをコピーする
composer install
npm install
Set up environment variables:

Copy the .env.example file to .env and configure your database and Cloudinary settings.
Run migrations:

bash
コードをコピーする
php artisan migrate
Serve the application:

bash
コードをコピーする
php artisan serve
Access the app:
Visit http://localhost:8000 in your browser.

📖 Usage
Create New Posts:
Share your travel experiences by filling out the location, category, and uploading photos.

Explore the Map:
Navigate through your trips via an interactive map interface powered by Leaflet.js.

🛠️ Technologies Used
Backend: Laravel
Frontend: Leaflet.js
Cloud Storage: Cloudinary
Database: MySQL
